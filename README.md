# Cacao aroma corridor pipeline

A reproducible, spreadsheet-first Python pipeline for projecting published cacao fruity-aroma association and candidate-gene architecture across heterogeneous cacao marker panels.

The pipeline implements the core analysis used for genomic corridor portability: marker catalog construction, pairwise marker continuity, association-zone recovery, candidate-gene recovery, and pathway-level recovery summaries. It writes Excel workbooks and does **not** generate publication figures.

## Repository scope

Included:

- core Python pipeline under `src/cacao_aroma_pipeline/`
- command-line runner under `scripts/run_pipeline.py`
- configuration file `pipeline_config.yaml`
- tests for core utility and overlap logic
- documentation for expected input files and generated outputs

Not included:

- third-party raw spreadsheets or publication supplementary files
- generated processed data and results
- downstream visualization scripts, exploratory analyses, or non-core analyses

## Expected project layout

Create a local project directory containing this repository code and a `data_raw/` directory with the source spreadsheets obtained from the original public sources.

```text
project_root/
  data_raw/
  data_processed/       # generated by the pipeline
  results/              # generated by the pipeline
  src/
  scripts/
  tests/
  pyproject.toml
  pipeline_config.yaml
```

The raw data files are not redistributed in this repository. See [`docs/DATA_SOURCES.md`](docs/DATA_SOURCES.md) for the expected input organization and primary source guidance.

## Installation

From an Anaconda Prompt or terminal opened at the repository root:

```bash
conda env create -f environment.yml
conda activate cacao-aroma-pipeline
pip install -e .
```

If the required packages are already installed in an existing environment:

```bash
pip install -e .
```

## Run the full analysis

```bash
python scripts/run_pipeline.py --project-root . run
```

or, after editable installation:

```bash
cacao-pipeline --project-root . run
```

The command scans `data_raw/`, normalizes supported spreadsheets, and writes outputs under `data_processed/` and `results/`.

## Configuration

Analysis windows and output behavior are controlled in `pipeline_config.yaml`.

Default windows:

- marker overlap: `0`, `10 kb`, `50 kb`, `250 kb`
- association recovery: `0`, `10 kb`, `50 kb`, `250 kb`
- candidate-gene recovery: `0`, `50 kb`, `250 kb`

## Reproducibility notes

This repository contains the code required to regenerate the core Excel outputs from locally obtained input spreadsheets. The pipeline is path-configurable and does not depend on absolute local directories. Generated data, logs, and Excel outputs are ignored by Git; users should regenerate them locally.
